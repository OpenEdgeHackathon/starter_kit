# OpenEdge Hackathon Starter Kit

## Download the OpenEdge MCP Server

The OpenEdge MCP Server is distributed as a GitHub Release because the file is too large to store in the repository itself.

### Steps

1. Go to the release page: [OPENEDGE_MCP_SERVER_1.0.0](https://github.com/OpenEdgeHackathon/starter_kit/releases/tag/1.0)
2. Scroll down to the **Assets** section at the bottom of the release.
3. Click the MCP server file to download it. Ignore the "Source code" entries, which GitHub adds automatically.
4. Unzip/extract the file if needed.
5. Follow the setup instructions in [the Progress Documentation](https://docs.progress.com/bundle/openedge-mcp-server/page/Install-OpenEdge-MCP-Server.html).

### Download via command line

```bash
curl -L -O https://github.com/OpenEdgeHackathon/starter_kit/releases/download/1.0/MCP.Server.Installer.zip
```
